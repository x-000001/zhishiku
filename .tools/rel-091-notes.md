# 0.9.1 – 视觉门面二改：近黑 ∞ 图标 + 品牌区粗细对比

## 这次改了什么

- **应用图标重画**：近黑 squircle 底板（#0A0B10）+ 白色双环 ∞ + 中心一粒极光蓝 #5EE7E6；顶部只留 1px 极弱内高光，去掉渐变和外投影。
- **多尺寸**：16/24/32/48/64/128/256 七档各自单独渲染（不是把 256 硬缩），≤32px 换一套几何，16px 下「∞」不断开、中心点不丢；托盘单独出 32px 版本。
- **侧栏品牌区**：28px 图标与桌面图标同源（内联 SVG 双环 + 极光点），右侧 `Jw`（700、青色）+ `知识库`（500、15px、0.5px 字距、正文字色），去掉渐变与文字阴影；间距 10px、留白 16px 20px；折叠成 60px 时只剩居中的图标。
- 版本号 0.9.0 → 0.9.1。
