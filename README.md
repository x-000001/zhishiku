# Jw 知识库

一个只在你电脑上运行的私人工作学习知识库：收集箱、知识库、任务待办、当前目标、下一阶段目标、学习计划、复习与复盘，加首页总览和数据备份——全部本地，不联网、不需要账号。

- 技术：Electron + React + TypeScript + CodeMirror 6 + SQLite（WAL）+ FTS5
- 数据：一个 SQLite 文件 + 一个附件文件夹 + 一个备份文件夹，都在 D 盘
- 需求原文：[PRD.md](PRD.md)　开发过程：[开发计划.md](开发计划.md)　验收清单：[验收清单.md](验收清单.md)

## 一、怎么打开（两种办法，任选一种）

### 办法一：绿色版（推荐，最省事）

双击这个文件即用：

```
C:\JwKB\portable\Jw知识库.exe
```

不需要安装、不需要管理员权限、不写注册表。整个 `C:\JwKB\portable` 文件夹可以拷到任何盘、
任何目录（U 盘也行），里面的 `Jw知识库.exe` 双击就能跑。删掉文件夹就等于卸载。

> 想要桌面图标：右键 `Jw知识库.exe` →「发送到」→「桌面快捷方式」。

### 办法二：安装版（会让桌面出现正式图标、可从控制面板卸载）

安装包：`C:\JwKB\setup\Jw知识库-安装包-0.3.0.exe`（约 107 MB）。

1. 双击 → 可能先被 Windows SmartScreen 拦一下，显示「Windows 已保护你的电脑」：
   因为安装包没买代码签名证书，显示「发布者未知」是正常的。点 **「更多信息」→「仍要运行」**。
2. 然后一路「下一步」；安装位置可以自己改。
3. 装完桌面出现「Jw知识库」图标，以后像普通软件一样双击打开。

> **不要去项目目录 `C:\Users\29785\Desktop\Jw的app\release\` 里双击安装包。**
> 那个目录被沙箱加了一条「Everyone 拒绝删除子目录和文件」的权限（保护工作区，属于预期行为）。
> 安装器启动时要在自己所在目录写一次临时文件再替换，被这条权限拒绝，就会弹：
> `NSIS Error: Error writing temporary file. Make sure your temp folder is valid.`
> 放在 `C:\JwKB\setup\` 这类普通目录里就正常（安装器本身没问题，是「在哪个目录运行」的问题）。
> 打好的安装包落在 `C:\JwKB\`，`release\` 里不再留安装包。

第一次打开会自动建好数据目录 `D:\Jw知识库`。

> 关窗口不会退出程序，它会缩到右下角托盘继续待命（这样才会到点提醒你）。真要退出：右键托盘图标 → 退出。

## 二、数据存在哪

默认全部在 `D:\Jw知识库\`：

```
D:\Jw知识库\
├─ kb.db                    主数据库（笔记、任务、收集箱、设置都在里面）
├─ kb.db-wal                运行时的写入日志（正常关闭会自动合并回 kb.db）
├─ kb.db-shm                SQLite 的共享内存文件（同上）
├─ attachments\             附件（图片、PDF 等），按年月分文件夹
│   └─ 2026-10\
└─ 备份\
    ├─ 2026-10-16_120301\   每天第一次打开时自动备份，只保留最近 7 份
    │   └─ kb.db
    └─ 恢复前_2026-10-16_121500\   从备份恢复前，先把当前数据另存一份
        └─ kb.db
```

数据目录的位置记在 `%APPDATA%\Jw知识库\locator.json`。

**想换到别的盘**（三种办法，按方便程度排）：

1. 设置页里能直接看到当前数据目录，点「打开数据文件夹」跳到它；
2. 用文本编辑器打开 `%APPDATA%\Jw知识库\locator.json`，把里面的路径改成新目录，重启软件；原目录的数据不会被删，自己确认没问题后再手动删；
3. 临时试一下：设环境变量 `JWKB_DATA_DIR` 再启动（设了这个就不会动 locator.json）。

## 三、备份与恢复

- **自动**：每天第一次打开软件时备份一次，`备份\` 里最多留最近 7 份；恢复前会先把「当前数据」另存成 `恢复前_...`，所以恢复也能反悔。
- **手动**：设置页 →「立即备份」。
- **恢复**：设置页 → 备份列表 →「恢复」（会弹二次确认）→ 数据回到那个时间点。
- **自检**：设置页 →「数据库自检」，出问题会直接告诉你。

数据不丢的七条保障（都已实现）：

1. 改动即时入库，没有「保存整个文档」这一步；
2. SQLite 跑 WAL 模式，断电最多丢最后一个没提交的动作，库不会坏；
3. 附件先写临时文件再改名替换，不会出现半个文件；
4. 关窗口先落盘再缩托盘；
5. 每天自动备份保留 7 份；
6. 恢复前先备份当前数据；
7. 启动时做一次完整性检查。

## 五、开发与自测

需要 Node.js（这台机器上是 v24）。

```powershell
npm install            # 装依赖（.npmrc 已经把源指向 npmmirror）
npm run dev            # 开发模式，边改边看
npm run build          # 只编译，产出 out\
```

测试（全部要跑通才算过关）：

```powershell
npm run typecheck      # TypeScript 类型检查，必须零错误
npm run test:unit      # 单元测试：数据库/迁移、富文本清洗、排序、路径、备份、性能
npm run test:e2e       # 端到端：真的启动 Electron，用 CDP 驱动界面点一遍
npm run test:kill      # 强杀测试：写 20 条数据后强杀进程，重开看数据还在不在
npm run test:all       # 上面全部按顺序跑一遍
```

- 单元测试和端到端测试的细节、最近一次结果：`tests\unit\`、`tests\e2e\last-result.txt`、`tests\e2e\last-kill-result.txt`
- 端到端测试会给 9 个页面截图，放在 `tests\e2e\shots\`

### 打包

```powershell
npm run pack           # 只生成绿色版，产出 release\win-unpacked\
npm run dist           # 生成安装包 + 绿色版，交付到 C:\JwKB\
```

打完包后**安装包不在 `release\` 里**，而在：

```
C:\JwKB\setup\Jw知识库-安装包-<版本>.exe     ← 双击这个安装
C:\JwKB\portable\Jw知识库.exe                ← 免安装绿色版，双击即用
C:\JwKB\使用说明.txt
```

交付目录可以用环境变量 `JWKB_OUT_DIR` 改（**不要设成桌面**，见下）。

> **为什么安装包必须放在项目目录之外？**
> 项目目录 `C:\Users\29785\Desktop\Jw的app` 上有一条「Everyone 拒绝 删除子目录和文件」的权限项
> （DSH 沙箱为保护工作区加的，属于预期行为，不要手动删）。NSIS 安装器启动时会先在自己所在目录
> 写一次临时文件，被这条权限拒绝，于是弹
> `NSIS Error: Error writing temporary file. Make sure your temp folder is valid.`
> —— 2026-10-16 就是在 `release\` 里双击踩到的。`build-installer.mjs` 现在打完包会把 `release\`
> 里的 exe 删掉、只留 `win-unpacked\`，并写一份「请先看这里.txt」，免得再踩。

> **为什么不能把交付目录设成「桌面」？**
> DSH 沙箱对工作区之外的写入可能被重定向：命令行里复制成功、`Test-Path` 也返回 True，
> 但真实桌面上什么都没有。所以默认交付到 `C:\JwKB`（盘根、纯英文、一定看得见）。
> 这一条是 2026-10-16 用「换一条新命令重新 stat」的方式确认的。

> **打包暂存路径**：`npm run dist` 走的是 `.tools\build-installer.mjs`，它先把 `out\`、`resources\`、
> `package.json` 复制到 `C:\jwkb-build`，用目录联接挂上 `node_modules`，在那边打完包再拷回来。
> 因为 electron-builder 调用的 `makensis.exe` 用 `!tempfile` 在「脚本所在目录」建临时文件，
> 路径里有中文（本项目目录叫 `Jw的app`）就会报 `!tempfile: Unable to create temporary file!`。
> 暂存目录可以用 `JWKB_BUILD_DIR` 改，同样必须是英文路径。

> **安装器的另一处隐患（已修）**：electron-builder 默认生成的安装器里，「检查程序是否已经在运行」
> 是用 `nsExec` 调 PowerShell 实现的，`nsExec` 要写临时文件；在部分机器上（PowerShell / CIM 被策略
> 限制时）这一步会直接失败，连窗口都出不来。修法是 `electron-builder.yml` 里加
> `nsis.include: installer.nsh`，由 `resources\installer.nsh` 提供一个空的 `customCheckAppRunning`
> 宏把这一步替换掉——安装流程从此不调 PowerShell、不写临时文件。代价：安装器不再帮你关掉正在运行
> 的旧版本，升级前自己先退出程序。（`resources\installer.nsh` 里只允许写 ASCII 注释：NSIS 读
> include 文件用系统代码页，中文有编译风险。）

## 六、做了哪些模块

### 第一版（外壳 + 数据 + 四个可用模块）

应用外壳（托盘、全局快捷键、单实例）、数据层（SQLite + WAL + FTS5 中文全文搜索 + 每天自动备份）、首页总览、快速收集箱、知识库（分类树、编辑、版本点、标签、全文搜索、附件、回收站、清理模式）、任务待办（五种视图、优先级、截止日、重复、行内编辑、收件箱式快速录入）、设置（数据位置、备份恢复、版本点数量、主题、通知开关、托盘行为）。

### 第二版（补齐剩下四个模块，2026-10-16）

| 模块 | 现在能做什么 |
|---|---|
| **当前目标** | 目标 + 关键结果（KR）+ 里程碑。进度自动算：重点看 KR 完成度，没拆 KR 就退回看关联任务的完成率。同时最多 3 个「进行中」的目标，多了会提示先收尾一个 |
| **下一阶段目标** | 现在还不做、但有想法的目标先放进「池子」：写清为什么想做、什么条件下启动、地平线是近期还是以后。条件到了点「启动」，它就变成当前目标 |
| **学习计划** | 计划 = 方向（含节奏与起止日期），下面挂条目；条目排到具体日期就出现在日历里，可增删改；首页「今日学习」直接取当天要学的条目。计划和任务分得清：计划是安排，任务是待办 |
| **复习与复盘** | 卡片来源分三类：笔记、错题、难点。三档打分（忘了 / 模糊 / 记得），间隔按 1 → 2 → 4 → 7 → 15 → 30 → 60 → 120 天自动拉长，忘了就回到 1 天。每篇笔记可以一键变成复习卡（同一篇不会重复生成）。日 / 周 / 月复盘分开写，旁边自动算出这段时间完成了多少任务、动了多少笔记、复习几次、计划条目完成几条 |

顺手补掉的第一版遗留：拖文件进编辑器直接存成附件、优先级四档（无 / 低 / 中 / 高）、任务的精确提醒时间、任务详情里选关联目标。

### 第三版（笔记与任务的体验补齐，2026-10-16 晚）

| 项 | 现在能做什么 |
|---|---|
| **富文本笔记** | 编辑器换成所见即所得：加粗 / 斜体 / 下划线 / 字体颜色 / 背景高亮 / 撤销 / 重做。重点标注就是「加粗 + 字色 + 背景高亮」这一套，Word 里粘过来的样式会被洗干净后保留下来 |
| **笔记图片** | 工具栏「🖼」选图、也可以直接拖进编辑器或粘贴截图。图片会复制进数据目录的 `attachments/YYYY-MM/`，正文里只存 `jw-att://` 相对地址（换盘符、换目录都不失效）；删除笔记不会连带删图 |
| **笔记表格** | 工具栏「⊞」选行列数插入；光标放进单元格后工具栏会多出「＋行 / －行 / ＋列 / －列」。表格跟着富文本一起存，重开结构不丢 |
| **知识库分类** | 分类树支持二三级子分类、新建 / 重命名；每个分类行有「↑ / ↓」在同一层里换位；**分类下还有笔记就删不掉**（会连子分类里的笔记一起数，提示「该分类下还有笔记，请先移动或删除笔记」）；删空分类时子分类自动上提一级 |
| **笔记卡片拖动排序** | 按住卡片拖动即可排序，松手立刻生效并写库，重开顺序不变；只在「当前分类、没有搜索关键字、没有标签筛选」时可拖，拖动只影响当前分类 |
| **任务勾选后不消失** | 今天 / 接下来 / 逾期三个视图不再把已完成的任务藏起来——勾完变灰加删除线并排到最后；左栏另有「全部 / 未完成 / 已完成」三档筛选（带条数） |
| **任务多选与批量删除** | 左栏「多选」进入多选模式：每行一个复选框，可全选 / 取消全选，选中后「批量删除」会先弹确认框再删 |
| **任务优先级三档** | 由四档数字改成三档文字：紧急（红）/ 重要（橙）/ 一般（蓝）。新建任务、详情抽屉都能选，列表按紧急在前排，左栏可只看某一档；老数据自动迁移（3 → 紧急、2 → 重要、1 和 0 → 一般） |
| **手动保存** | 笔记编辑页、目标编辑页、任务详情抽屉、设置页都有「保存」按钮，点一下就是一次真写盘，成功提示「已保存 16:40:27」。失败会分诊告诉你原因：被其它软件占用 / 权限不足 / 磁盘满 / 数据文件损坏，各有各的中文提示。自动保存照旧（草稿自动留、失焦即存），两者不冲突 |

**不做**（一直不做）：登录（永久不做）、云同步与联网、手机端、密码锁。

### 第四版（界面重构，2026-10-16 晚）

只动外观，功能、数据结构、快捷键、交互动作一个都没变（改动集中在 `src/renderer/src/styles.css`）。

| 项 | 现在长什么样 |
|---|---|
| **整体观感** | 参考 Linear / Notion / Things 那类工具的做法：中性灰底 + 白色卡片、1px 细边框、柔和的层叠阴影、克制的圆角（8 / 12px），排版按 8px 节奏排，字号与字重分了三层（标题 600+、正文常规、辅助信息弱色） |
| **侧栏** | 侧栏改成浅灰底，导航项是圆角胶囊；当前页是「白底 + 细边 + 小投影」，更像一个被选中的卡片；数量徽标改成胶囊；这一栏的底色与正文区拉开层次，但不再用重描边 |
| **按钮与输入框** | 统一的 34px（小号 28px）高度、圆角、悬停/按下/禁用四态；主按钮是品牌色实心 + 细投影；输入框有聚焦环（brand 色 3px 光晕），`Esc` / 键盘操作都没变 |
| **分段控件** | 复习/复盘、状态、优先级这几种「切换一组」的地方，统一成灰底容器 + 选中项白底小投影的分段控件观感 |
| **卡片与列表** | 卡片有细边 + 悬停时轻微加深；列表行悬停浅灰、选中是品牌浅底 + 左侧 2px 高亮条；任务行的完成勾选是圆形复选框（勾上填品牌色） |
| **写作区** | 编辑器工具条与正文之间是浅灰工具条；正文按 `clamp(20px, 7%, 120px)` 的左右留白排成一条舒适的阅读宽度（不会一行拉到屏幕尽头）；表格有表头底色与圆角，引用块是细高亮条 + 浅底，图片圆角 + 轻投影 |
| **暗色主题** | 暗色重做了表面层级（#101114 底 / #17181c 面板 / #131418 沉底）与文字对比，主色换成更亮的靛蓝，长文阅读不刺眼；`设置 → 深色` 切换即可对照 |
| **细节** | 滚动条变细并跟随主题；弹窗是 16px 圆角 + 重投影 + 背景模糊；提示条（toast）是深色胶囊 + 上浮动画；窄窗口（<1080px）首页自动收成一列；系统开启「减少动态效果」时所有过渡动画自动关掉 |

**同样不做**：不改任何 DOM 结构与类名（e2e 的 149 项断言原样全过），不改任何键位与交互动作。

### 第五版（macOS 毛玻璃 + 原生手感，进行中）

目标风格：macOS 天气 App 那种毛玻璃质感 + macOS 的交互手感。**只动外观与手感，功能、数据结构、快捷键、业务逻辑一行不改。**

做法：优先纯 CSS。新增的 DOM 只有一处 —— 侧栏左上角那三个红黄绿按钮（窗口改成无边框之后，它就是系统标题栏）。

| 阶段 | 做了什么 | 能看到什么 |

**阶段6 怎么验收**：① 首页右上「当前目标进度」→ 每个目标左边是一个**环形进度**（环里写着百分比），加载时会转着长出来，下面的进度条变成了蓝色渐变 + 一道高光；② 造一条截止日在昨天的任务 → 首页「已经逾期」那格变红并轻轻呼吸，任务行左边一道红杠、标题与日期都转红；③ 今天的计划里勾掉一条 → 标题被划掉、勾是绿的，勾上的一瞬间会弹一下；④ 目标页打开一个目标 → 「里程碑」变成**时间轴**：一颗竖线把检查点串起来，完成的段落是绿的、没完成的还是灰的。

**顺手修的 bug · 展开侧栏不再闪跳（2026-10-16 晚）**：病因有两个 —— ①「知识库」「首页」这些文字是**折叠时卸载、展开时挂载**的，展开那一帧文字就整块冒出来，而侧栏宽度还在 60 → 232px 地长，于是「先闪一下再挤过去」；② 左上角三个点是 `display: none` 藏的，展开时突然插回来把品牌行整块推开。治法：文字与圆点**一直留在 DOM 里**（`.brand-text / .nav-label / .foot-text / .count`），折叠时把 `max-width` 收成 0、`opacity` 收成 0、`translateX(-6px)`，和侧栏宽度走同一条 180ms 缓停曲线；三个点也从 `display` 切换改成「宽度 + 透明度」收起。e2e 新增两条回归断言（收起后文字宽 0 但**仍在 DOM**；展开时三条过渡都接上了且宽度单调长回去），并尊重系统「减少动态效果」。

**顺手修的 bug · 折叠时三个点竖排、Jw 图标不再被切（2026-10-16 晚）**：上一版折叠后三个点收成 0 宽度，于是 ① 窗口没了关闭/最小化按钮；② `.brand` 是横排 + `overflow: hidden`，内容盒只有 24px，而 `0 + 9 + 28 + 9 = 46px`，**「Jw」图标右半边被裁掉**。治法（纯 CSS）：折叠时 `.brand` 改竖排（三个点在上、图标在下，左右内边距归零），`.win-lights` 用 `flex-wrap` + 宽度 `52px ↔ 12px`，三个点就顺着同一条 180ms 曲线**逐个换行**成竖排，不是硬切。e2e 把原断言改写成「三点 12×46 竖排 + 图标 28px 完整（右侧溢出 ≤1px）」，展开断言补「三点回到一排 52×12」，全过（总数 181 项）。

**顺手修的 bug · 三个点不卡、名字不再弹两遍、气泡改成 macOS 手感（2026-10-16 晚）**：① 折叠/展开时三个点会卡一下 —— 根因是 `.win-lights` 用 `width: 52px ↔ 12px` 插值，逼浏览器对整行做布局；改成**只动 transform**（容器只过渡 `opacity` 0.12s，三颗点各自 `translate(-12px,17px)`、`translate(-24px,34px)` 走弹簧曲线换位）；② 侧栏展开后鼠标停在导航上不该再冒名字 —— 原先靠 `title`（系统提示），整个去掉，改 `data-tip` + CSS 气泡，并且只在 `.sidebar.collapsed` 下才 `opacity: 1`；③ 折叠态气泡太生硬 —— 按 macOS 提示条重做：深色半透明 `color-mix(#1b1c21 88%, transparent)` + `blur(14px) saturate(160%)` + 7px 圆角 + 12px 字 + 内侧 1px 高光，停 0.32s 后从左侧 6px 处弹簧推出来。为了让它浮出 60px 宽的侧栏：`.nav`（滚动容器）在窗口 ≥700px 高时放开裁剪（短窗口保留滚动），`.sidebar` 只在「折叠 + 悬停」这一下放开 `overflow` 并抬到 `z-index: 45`（否则会被正文卡片盖住）。e2e 新增一条断言（`title` 为空 + 展开态 opacity 0 + 折叠态内容/圆角/模糊/延迟/两层溢出）与一张截图 `tests/e2e/shots/sidebar-nav-tip.png`。

**顺手修的 bug · 换了主题点「放弃改动」退不回去（2026-10-16 晚）**：设置页的「主题」是**边选边预览**的（选浅色当场就变浅色，这样才好判断），但「放弃改动」原来只把表单值改回上次保存的值，界面上的颜色还留着预览的那个 —— 于是出现「深色切浅色再取消，依旧是浅色」。现在「放弃改动」除了回滚表单，也会把主题退回上次保存的那个（连 `localStorage` 镜像一起），并且在**离开设置页时**兜底退回，避免「界面是预览色、库里还是旧主题」；主题说明里也把「先预览、点保存才记住」写清楚。e2e 新增一条断言（把主题切到和库里不同的那个 → 点「放弃改动」→ `data-theme`、下拉框、镜像三处都要等于库里的值）。

**顺手修的手感问题 · 拖窗口时侧栏收成图标条会「卡一下」（2026-10-17）**：拖动窗口时 resize 每一帧都在改尺寸，而侧栏那条 180ms 的宽度插值还跑在同一条时间轴上 —— 侧栏右边缘得一帧一帧「追」窗口右边缘。实测拖到 1100 那一路上，侧栏宽度是 `232→228→213→179→138→107→88→75→68→63→61→60` 这么一帧帧插下去的，最多落后窗口 172px，正文宽度也跟着被拽了 6 次（每次 20–42px 不等）。帧本身其实没掉（这台机器 p95 17.7–18.2ms、没有 >33ms 的帧），肉眼那种「不流畅」就是这一下下错位攒出来的。现在拖动期间给 `<html>` 挂 `.is-resizing`，CSS 把插值/动画全关掉：侧栏宽度只在 232 和 60 之间瞬切一次（「啪」一下收好），之后每帧只跟着指针走 8px，正文抖动帧 6 → 2（剩下两次是跨档瞬切和 1199px 那条媒体查询的 20px 台阶，躲不掉）；停手 150ms 后类自己摘掉，点底部 `»` 折叠、点汉堡滑出抽屉这些**不是拖动**的动画照旧。量法是 `.tools/perf-resize.mjs`：真开窗口、用 Win32 每步 8px 地缩，渲染层 rAF 逐帧记侧栏/正文宽度。e2e 也加了一条断言：派发一次 resize → 立刻 `.is-resizing` 在、`.sidebar` 的 `transition-duration` 是 `0s`；等 400ms → 类自己摘掉、过渡恢复 `0.38s`。

**阶段9.5 怎么验收（动画专项）**：① 点侧栏底部的 `»` 收起、再点展开 → 面板是**缓缓**滑出去的（约 0.4 秒，比原来慢一倍），全程图标与文字**不会一边动一边重新排版**（不会出现文字被挤着换行的碎动），三个点也留在原地；② 动画那半秒里盯着侧栏底：是**实色**的玻璃底（浅色 `#fff`、深色 `#22242f`），动画一结束立刻变回半透明磨砂，**不该看到闪一下或者边缘发白**；③ 知识库列表把鼠标上下划 → 行只轻轻上浮 1px，不抖；④ 造 60 条以上笔记再切分类 → 列表是**整块淡入**，而不是 60 行各自动一次（超过 50 条时才这样，少量笔记仍逐行过渡）；⑤ 系统「减少动态效果」打开时，收起/展开仍然是瞬间完成（不做动画、也不挂毛玻璃降级类）。

**阶段10 怎么验收（弹窗与右键菜单）**：① 知识库页右键任意一条笔记 → 菜单在鼠标处弹出、是毛玻璃，里面有「打开 / 置顶 / 移到回收站」；右键左侧某个分类 → 「新建子分类 / 改名字 / 上移 / 下移 / 删除分类」；任务页右键一行 → 「标记完成 / 优先级 / 删除」；② 把窗口开到最右下角再右键 → 菜单自动往左上拐，不会有一半在屏幕外；③ 按 ↑ ↓ 在菜单里挪（高亮跟手），Enter 执行、Esc 收起、点菜单外面也收起；④ 点「改名字」→ 弹窗从下方 6px 处淡入 + 放大出现，光标已经在输入框里；点右上角 ✕（或按 Esc、点遮罩）→ 先淡出缩回再消失（不是瞬间没掉）；页面自己画在弹窗底部的「取消」按钮沿用原来的瞬时关闭，先动的那一下动画仍然在；⑤ 把窗口拖到 720 宽再点「改名字」→ 弹窗从**底部升起来占满整宽**，下面两角是直角、能直接按上面的输入框。

**阶段11 验证时顺手修的两处**（都是这一轮加断言才暴露的）：
- **弹窗挂到 body 上**：弹窗原来渲染在页面自己的玻璃面板（`.kb`）里，而玻璃面板的 `backdrop-filter` 会让 `position: fixed` 以**它为参照物**（不是窗口）——所以 720 宽时底部面板量出来只有 688/720 宽。现在 `Modal` 用 `createPortal` 挂到 `document.body`，窄窗口占满整宽、位置也对。
- **右键菜单贴边夹取改用 `offsetWidth/offsetHeight`**：入场动画带 `scale`，`getBoundingClientRect()` 量到的是缩放后的尺寸（偏小），在右下角右键时菜单会露出窗口外。换成不受 transform 影响的布局尺寸后就收得回来了。

**顺手修的 bug · 深色模式下分段标签「白底白字」（2026-10-17 晚）**：复习与复盘页顶部的「复习 / 复盘」、日 / 周 / 月复盘，下一阶段目标页「目标池」的五个标签，学习计划页的「条目 / 日历」——这些分段标签在代码里是**裸 `<button>`**（只挂一个 `.on` 表示选中，没有 `.btn` 类），所以一直靠浏览器的默认外观在画。默认外观是**浅灰底** `rgb(240, 240, 240)`，而文字颜色继承深色主题的近白 `rgb(232, 232, 237)` → 对比度只剩 **1.07 : 1**，等于白底白字，完全看不见（浅色模式下文字是深色，所以看不出问题）。修法没碰 JSX（按「只改样式」的要求）：① 给 `.tabs > button:not(.btn)` 补一套吃主题变量的分段控件样式——未选中透明底 + `--text-soft`、悬停 `--bg-hover`、选中 `--bg-panel` + `--border` + `--text`，深色下就是「容器暗底 + 半透明胶囊 + 浅字」；② 顺手在 `:root` / `[data-theme='dark']` 上加 `color-scheme: light / dark`，让所有原生控件（选择框弹层、日期选择器，以及以后再冒出来的裸 button）自动跟着主题走，从根上不再出现「浅色控件落在深色页面」。实测对比度：深色选中 **12.63 : 1**、未选 **13.6 : 1**；浅色选中 **17.06 : 1**、未选 **15.08 : 1**（无障碍阈值 4.5 : 1）。量法是 `.tools/probe-darktabs.mjs`（真开应用，逐主题、逐页面算相对亮度）。e2e 加了两条断言：深色 / 浅色各一条，各遍历「复习与复盘」「下一阶段目标」两个页面的所有分段标签，取最低对比度必须 ≥ 4.5。

**顺手做的表单呼吸感 · 「加一张卡片」「记一个以后想做的事」太挤（2026-10-17 晚）**：这两张表单原来沿用全站最紧凑的那套行样式——输入框内边距只有 `6px 9px`、标签只占 62px 且是垂直居中、行与行之间没有额外间距、下拉和按钮的高度也各不相同。现在只调间距与高度、**一个颜色都没动**：标签改成**顶部对齐**（多行文本框时不再「忽上忽下」）并给到 96px 宽（「什么条件下启动」这种长标签也不折行）；单行输入框与下拉统一 **40px 高、内边距 9px / 14px**；多行文本框 **70px 起、行高 1.7**、可拖右下角调高；每行之间留 **15px**；卡片标题到第一行 16px；下拉的右侧留 34px 给箭头；「加上 / 记下来」按钮也统一到 40px 高。范围用 `.dash-grid .card > .field` 精确圈住这两张表单（任务页、计划页那种密集的筛选行不受影响）。e2e 加了两条断言：一条量「控件 40px、内边距 9/14、行距 15px、文本框行高 1.7」，一条确认控件颜色仍然跟着主题走（深色 12.63 : 1、浅色 17.06 : 1，没有被写死成白底）。

- **回收站里不再提供逐条的「彻底删除」**：物理删除只保留「清空回收站」这一条路（它本来就有确认框，也写明不能撤销），另外就是满了 30 天自动清理。物理删除的接口留着没删（主进程内部还在用），界面上只是不给逐条入口了。
- 列表面板里的「彻底删除」文案全部清掉，跟实际行为对齐。
