# Jw 知识库

一个只在你电脑上运行的私人工作学习知识库：收集箱、知识库、任务待办、当前目标、下一阶段目标、学习计划、复习与复盘，加首页总览和数据备份——全部本地，不联网、不需要账号。

- 技术：Electron + React + TypeScript + CodeMirror 6 + SQLite（WAL）+ FTS5
- 数据：一个 SQLite 文件 + 一个附件文件夹 + 一个备份文件夹，都在 D 盘
- 需求原文：[PRD.md](PRD.md)　开发过程：[开发计划.md](开发计划.md)　验收清单：[验收清单.md](验收清单.md)

## 一、怎么打开（两种办法，任选一种）

### 办法一：绿色版（推荐，最省事）

桌面上的 **「Jw知识库」快捷方式**指的就是它，双击即用：

```
C:\Users\29785\Desktop\Jw知识库（绿色版）\Jw知识库.exe
```

不需要安装、不需要管理员权限、不写注册表。整个「Jw知识库（绿色版）」文件夹可以拷到任何盘、
任何目录（U 盘也行），里面的 `Jw知识库.exe` 双击就能跑。删掉文件夹就等于卸载。

### 办法二：安装版（会让桌面出现正式图标、可从控制面板卸载）

安装包：`C:\Users\29785\Desktop\Jw知识库安装包\Jw知识库-安装包-0.1.0.exe`（约 108 MB）。

1. 双击 → 可能先被 Windows SmartScreen 拦一下，显示「Windows 已保护你的电脑」：
   因为安装包没买代码签名证书，显示「发布者未知」是正常的。点 **「更多信息」→「仍要运行」**。
2. 然后一路「下一步」；安装位置可以自己改。
3. 装完桌面出现「Jw知识库」图标，以后像普通软件一样双击打开。

> 如果弹出 `NSIS Error: Error writing temporary file. Make sure your temp folder is valid.`，
> 说明你运行的是**旧版**安装包。新版已经把那一步（安装器启动时调 PowerShell 去检查程序是否在
> 运行、需要写临时文件）整个换成了不写临时文件的实现，见第五章「打包」。

第一次打开会自动建好数据目录 `D:\Jw知识库`。

> 关窗口不会退出程序，它会缩到右下角托盘继续待命（这样才会到点提醒你）。真要退出：右键托盘图标 → 退出。

## 二、数据存在哪

默认全部在 `D:\Jw知识库\`：

```
D:\Jw知识库\
├─ kb.db                    主数据库（笔记、任务、收集箱、设置都在里面）
├─ kb.db-wal                运行时的写入日志（正常关闭会自动合并回 kb.db）
├─ kb.db-shm                SQLite 的共享内存文件（同上）
├─ attachments\             附件（图片、PDF 等），按年月分文件夹
│   └─ 2026-10\
└─ 备份\
    ├─ 2026-10-16_120301\   每天第一次打开时自动备份，只保留最近 7 份
    │   └─ kb.db
    └─ 恢复前_2026-10-16_121500\   从备份恢复前，先把当前数据另存一份
        └─ kb.db
```

数据目录的位置记在 `%APPDATA%\Jw知识库\locator.json`。

**想换到别的盘**（三种办法，按方便程度排）：

1. 设置页里能直接看到当前数据目录，点「打开数据文件夹」跳到它；
2. 用文本编辑器打开 `%APPDATA%\Jw知识库\locator.json`，把里面的路径改成新目录，重启软件；原目录的数据不会被删，自己确认没问题后再手动删；
3. 临时试一下：设环境变量 `JWKB_DATA_DIR` 再启动（设了这个就不会动 locator.json）。

## 三、备份与恢复

- **自动**：每天第一次打开软件时备份一次，`备份\` 里最多留最近 7 份；恢复前会先把「当前数据」另存成 `恢复前_...`，所以恢复也能反悔。
- **手动**：设置页 →「立即备份」。
- **恢复**：设置页 → 备份列表 →「恢复」（会弹二次确认）→ 数据回到那个时间点。
- **自检**：设置页 →「数据库自检」，出问题会直接告诉你。

数据不丢的七条保障（都已实现）：

1. 改动即时入库，没有「保存整个文档」这一步；
2. SQLite 跑 WAL 模式，断电最多丢最后一个没提交的动作，库不会坏；
3. 附件先写临时文件再改名替换，不会出现半个文件；
4. 关窗口先落盘再缩托盘；
5. 每天自动备份保留 7 份；
6. 恢复前先备份当前数据；
7. 启动时做一次完整性检查。

## 五、开发与自测

需要 Node.js（这台机器上是 v24）。

```powershell
npm install            # 装依赖（.npmrc 已经把源指向 npmmirror）
npm run dev            # 开发模式，边改边看
npm run build          # 只编译，产出 out\
```

测试（全部要跑通才算过关）：

```powershell
npm run typecheck      # TypeScript 类型检查，必须零错误
npm run test:unit      # 单元测试：数据库、路径、Markdown、备份、性能
npm run test:e2e       # 端到端：真的启动 Electron，用 CDP 驱动界面点一遍
npm run test:kill      # 强杀测试：写 20 条数据后强杀进程，重开看数据还在不在
npm run test:all       # 上面全部按顺序跑一遍
```

- 单元测试和端到端测试的细节、最近一次结果：`tests\unit\`、`tests\e2e\last-result.txt`、`tests\e2e\last-kill-result.txt`
- 端到端测试会给 9 个页面截图，放在 `tests\e2e\shots\`

### 打包

```powershell
npm run pack           # 只生成绿色版，产出 release\win-unpacked\
npm run dist           # 生成安装包，产出 release\Jw知识库-安装包-<版本>.exe
```

> **注意 `npm run dist` 必须在英文路径下打包。**
> electron-builder 会调用 NSIS 的 `makensis.exe`，它的 `!tempfile` 宏会在「脚本所在目录」建临时文件——
> 只要这个目录里有中文（本项目目录叫 `Jw的app`），就会报
> `!tempfile: Unable to create temporary file!` 然后打包失败。
> 所以 `npm run dist` 走的是 `.tools\build-installer.mjs`：它先把 `out\`、`resources\`、`package.json`
> 复制到 `C:\jwkb-build`，用目录联接挂上 `node_modules`，在那边打完包再把 exe 拷回 `release\`，
> 并另外往 `桌面\Jw知识库安装包\` 存一份可直接双击的副本（想换位置就设环境变量 `JWKB_OUT_DIR`）。
> 想换暂存目录就设环境变量 `JWKB_BUILD_DIR`（同样必须是英文路径）。
>
> **还有一个运行期的坑（已修）**：electron-builder 默认生成的安装器里，
> 「检查程序是否已经在运行」这一步是用 `nsExec` 调 PowerShell 实现的，`nsExec` 需要写临时文件——
> 在部分机器上这一步会直接失败，弹出 `NSIS Error: Error writing temporary file.
> Make sure your temp folder is valid.`，安装器连窗口都出不来。
> 修法是 `electron-builder.yml` 里加了 `nsis.include: installer.nsh`，由 `resources\installer.nsh`
> 提供一个空的 `customCheckAppRunning` 宏，把这一步整个替换掉——安装流程从此不调 PowerShell、
> 不写任何临时文件。代价：安装器不再帮你关掉正在运行的旧版本，升级前自己先退出程序。
> （`resources\installer.nsh` 里只允许写 ASCII 注释：NSIS 读 include 文件用系统代码页，中文有编译风险。）

## 六、做了哪些模块

### 第一版（外壳 + 数据 + 四个可用模块）

应用外壳（托盘、全局快捷键、单实例）、数据层（SQLite + WAL + FTS5 中文全文搜索 + 每天自动备份）、首页总览、快速收集箱、知识库（分类树、编辑、版本点、标签、全文搜索、附件、回收站、清理模式）、任务待办（五种视图、优先级、截止日、重复、行内编辑、收件箱式快速录入）、设置（数据位置、备份恢复、版本点数量、主题、通知开关、托盘行为）。

### 第二版（补齐剩下四个模块，2026-10-16）

| 模块 | 现在能做什么 |
|---|---|
| **当前目标** | 目标 + 关键结果（KR）+ 里程碑。进度自动算：重点看 KR 完成度，没拆 KR 就退回看关联任务的完成率。同时最多 3 个「进行中」的目标，多了会提示先收尾一个 |
| **下一阶段目标** | 现在还不做、但有想法的目标先放进「池子」：写清为什么想做、什么条件下启动、地平线是近期还是以后。条件到了点「启动」，它就变成当前目标 |
| **学习计划** | 计划 = 方向（含节奏与起止日期），下面挂条目；条目排到具体日期就出现在日历里，可增删改；首页「今日学习」直接取当天要学的条目。计划和任务分得清：计划是安排，任务是待办 |
| **复习与复盘** | 卡片来源分三类：笔记、错题、难点。三档打分（忘了 / 模糊 / 记得），间隔按 1 → 2 → 4 → 7 → 15 → 30 → 60 → 120 天自动拉长，忘了就回到 1 天。每篇笔记可以一键变成复习卡（同一篇不会重复生成）。日 / 周 / 月复盘分开写，旁边自动算出这段时间完成了多少任务、动了多少笔记、复习几次、计划条目完成几条 |

顺手补掉的第一版遗留：拖文件进编辑器直接存成附件、优先级四档（无 / 低 / 中 / 高）、任务的精确提醒时间、任务详情里选关联目标。

**不做**（一直不做）：登录（永久不做）、云同步与联网、手机端、密码锁。

逐条验收证据见 [验收清单.md](验收清单.md)，开发过程见 [开发计划.md](开发计划.md)。
